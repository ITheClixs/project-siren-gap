## 1. Rungs (frozen definitions)

Each rung is a feature map applied to the same underlying corpus, decoded by the same apparatus.
`D` is the decoder input dimension; the raw sine INR has D = 1185 (L=2, w=32).

| rung | features | corpus | class |
|---|---|---|---|
| P0 | real pixels (784) | — | deterministic |
| P1 | oracle render of the fitted INR on the fit grid (784) | P-shared-det | deterministic |
| W1 | raw flattened weights | P-shared-det | deterministic |
| W2 | raw flattened weights | P-shared-stoch | deterministic |
| W3 | raw flattened weights | P-random | deterministic |
| W4 | `c_sort` canonicalization (neuron sort) | P-random | deterministic |
| W5 | `c_align` canonicalization (sort + sign/phase alignment) | P-random | deterministic |
| W6 | raw weights + bounded group augmentation at train time (perm ⊕ σ ⊕ τ/ρ with \|j\| ≤ 1) | P-random | **augmentation-bearing** |
| W7 | K-marginalization: all K=8 fitted views per train image as separate training rows | P-random-K (train) + P-random (val/test) | deterministic |
| W8 | best composition of {W4 or W5} ⊕ W6-style augmentation | P-random | **augmentation-bearing** |
| W9 | frame averaging over R ∈ {4, 16, 64} group elements | P-random | deterministic |
| W10 | phase-invariant encoding (L=1-scoped: layer-1 + output invariant features, PO-4 Φ) | P-random | deterministic |
| X1 | decoder trained on W1 features, evaluated on W3 features (and the reverse) | both | deterministic |

**Class definition (drives the seed policy, §4):** a rung is *augmentation-bearing* iff its decoder
input is re-drawn during training. W9's frame elements are drawn **once per seed and then held
fixed** (a fixed frame, not a resampled one), which places it in the deterministic class; this is a
freeze-time decision made to keep W9 affordable, and it is what "frame averaging" will mean in the
thesis.

W7 note: the val/test splits stay single-view (K=1) so that every rung is scored on the same
evaluation set; only the training set is K-marginalized. Its training set is therefore 8× larger,
which is a confound with sample size — the pre-committed control is W7-1/8, a W7 run subsampled to
one view per image (equal rows to W3), reported alongside.

## 2. Hypotheses (frozen wording, frozen numbers)

Point predictions carry 80% intervals and are scored per protocol §0.1.2.

- **H-S1-1 (information preservation).** P1 ≈ P0 by TOST at margin 1.0 pt.
  Registered: P1 − P0 = **+0.1 pt**, 80% [−0.4, +0.6].
- **H-S1-2 (decoder-vs-representation residual).** W1 − P1 = **−3.8 pts**, 80% [−6.5, −1.5].
  This is a *measurement*, not an equivalence claim: the anchor already puts W1 at 94.36 ± 0.21
  while a pixel/render MLP is expected near 98. Reported with a 95% CI; no TOST.
- **H-S1-3 (optimization noise).** W1 − W2 = **+2.0 pts**, 80% [0.0, +6.0]. Shared init keeps
  P-shared-stoch in the same basin (PO-9 laziness), so minibatch noise should cost little.
- **H-S1-4 (init/symmetry+basin, and how much canonicalization buys back).**
  W1 − W3 = **+80.4 pts**, 80% [79, 82] (re-measurement of anchor A1 under the frozen apparatus).
  Canonicalization recovery fraction f = (W4 − W3)/(W1 − W3): **f(W4) = 0.06**, 80% [0.01, 0.20];
  **f(W5) = 0.10**, 80% [0.02, 0.30]. Direction registered: f(W5) ≥ f(W4).
- **H-S1-5 (discriminator, RQ4 first cut).** (W7 − W3) − (W6 − W3) = **+15 pts**, 80% [+5, +35],
  i.e. marginalizing over the nuisance beats acting on it by the group. Directional claim, one-sided
  paired t within the Holm family below; TOST is not applicable.
- **H-S1-6 (invariant front-end).** W10 lands within **±3 pts** of the interval [W4, W5].

**Holm family** (α = .05 across these six): {H-S1-1, H-S1-2, H-S1-3, H-S1-4 (gap term),
H-S1-5, H-S1-6}. The f(W4)/f(W5) recovery fractions are reported with bootstrap CIs, not tested.

## 3. Decoder and probes (frozen)

Matched MLP `[D → 1024 → 512 → 256 → 10]`, GELU, dropout 0.1, AdamW lr 1e−3, cosine schedule,
≤ 100 epochs, batch 512, early stop on the INR val split (image ids 55000–59999), patience 10.
Per-dimension z-score standardization fit on the rung's own training features (part of the rung).
Linear probe (30 epochs, AdamW 1e−2, wd 1e−4) and kNN (k = 10, cosine) reported at every rung.
The test split is touched once per rung by the frozen configuration.

**Probe caveat, pre-committed:** for augmentation-bearing rungs the probes are computed on the
*unaugmented* feature matrix, so they equal the corresponding raw-rung probes by construction and
are reported as "n/a (identical to W3 by construction)" rather than as separate numbers. (The A1/A2
anchor JSON reported them as duplicated fields; that presentation is corrected here.)

## 4. Seed policy (from the power memo, `results/power/S1_power.json`)

Measured seed-to-seed SD of paired differences at the anchors: **0.210 pts** (A1, deterministic
rungs) and **0.721 pts** (A2, augmentation-bearing). Sizing uses the one-sided upper 80% confidence
limit of each SD (0.327 and 1.123), because an SD estimated from 5 seeds is itself noisy.

| class | planning SD | n seeds | MDE (α=.05, power .8) | TOST power at margin 1.0, Δ=0 |
|---|---|---|---|---|
| deterministic | 0.327 | **5** | 0.55 pt | ≈ 1.00 |
| augmentation-bearing | 1.123 | **15** | 0.87 pt | 0.90 |

At n = 5 the augmentation-bearing class would have MDE 1.89 pts and TOST power **0.20** — not
adequate for any claim at the 1.0-pt margin, which is why W6 and W8 get 15 seeds. Seeds are
0…n−1 (the same seeds across rungs, so all comparisons are paired by seed).

## 5. Analysis plan (frozen)

Per rung: mean ± 95% t-CI over seeds. Rung comparisons: paired-by-seed t **and** Wilcoxon (at n=5
the two-sided Wilcoxon floor is p = .0625 — reported alongside t, never as the sole evidence),
Cohen's d, Holm within the family of §2. Equivalence via TOST at margin 1.0 pt where §2 says so.
Label-shuffle control at W1, W3, W5: retrain with permuted labels, must collapse to ≈ 10%.
The waterfall figure F9 is built from these cells only.

## 6. Exclusion rules (frozen)

No row-wise exclusion of INRs: a corpus either passes its quality gate or is regenerated (a config
change makes a new pre-registration). A decoder run failing to exceed 15% val accuracy
(optimization collapse) is re-run at seed+1000 and flagged; more than one collapse in a rung
invalidates that rung's cell pending investigation.

## 7. Leakage handling (pre-committed)

Measured corr(PSNR, label) on the frozen corpora: MNIST +0.203 (P-shared-det), +0.017 (P-random),
+0.061 (P-shared-stoch); FashionMNIST −0.067 (P-shared-det), −0.124 (P-random-K). The sign flips
across datasets, so this is fit-difficulty structure, not a single artifact.

Trigger: for each headline rung (W1, W3, W7), regress per-image decoder correctness on PSNR within
class. If PSNR is a significant predictor at α = .05 **after** Holm across the three rungs, that
rung is re-run on a PSNR-matched subset — matched by stratifying PSNR into deciles within class and
subsampling to the minimum per-cell count — and *both* numbers are reported, with the matched one
carrying the claim.

## 8. Anticipated confounds, and what would falsify the story

1. **W7's 8× training rows** — controlled by W7-1/8 (§1).
2. **Feature dimension differs across rungs** (W10, W9 change D) — the matched MLP absorbs D in its
   first layer, so a rung could win by dimensionality alone. Control: report the linear probe next
   to the MLP for every deterministic rung; a rung that gains only in the MLP and not in the probe
   is flagged as capacity-driven in the write-up.
3. **The headline W1 − W3 gap is a decoder artifact** (a plain MLP has no permutation structure, so
   W3 is floor-level by construction). This is acknowledged as the intended reading of the rung —
   the ladder measures the gap *for a matched reader*, and X1 plus the canonicalization rungs are
   what separate "the reader is weak" from "the representation is scrambled". If W4/W5 recover most
   of the gap (f > 0.5, outside the registered interval), the thesis's canonicalization-is-not-
   enough claim (defense #3) is falsified and must be rewritten, not softened.
