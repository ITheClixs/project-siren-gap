# S18 Pre-registration — the phasor-graded reader at width 128 — FROZEN

**Study:** S18. Tests whether W12's result holds on networks with fourteen times the parameters.
**Frozen:** 2026-09-13, before any S18 cell is computed. Ledger rows `H-S18-*`, `P-S18-*`.

## Why

The width-128 arm (MNIST, 10k/2k/2k images, 300 steps, 17,025 parameters per INR) reproduced the
gap (84.9 points), the group intervention (85.7) and alignment ($f(c_{\mathrm{align}}) = 0.677$),
but the reader W12 was never run on it, so the paper cannot say its main reader holds at scale.

## Design

`scripts/47_w12_phasor.py`, unchanged, on `P-random-w128` and on `P-shared-det-w128`, with the
width-128 anchors (`results/ladder_w128/mnist/W1.json`, `W3.json`), 5 seeds, and the same capacity
rule as every other W12 run (reader matched to the frozen width-32 decoder's 1,873,162
parameters; the reader's size does not grow with the number of neurons it reads).

Quantities: $s(\mathrm{W12})$ on `P-random-w128`; the reader's shared-versus-random difference
$\mathrm{acc}(\texttt{P-shared-det-w128}) - \mathrm{acc}(\texttt{P-random-w128})$.

## Exposure

The width-128 anchors, W4, W5, W10 and the intervention are known (above). No W12 cell at width
128 has been computed.
