# S7 Pre-registration — the matched non-invariant control for W10 — FROZEN

**Study:** S7. Priority-3 of the external review. Ledger rows `H-S7-*`, `P-S7-*`.
**Frozen:** 2026-08-03, before the rung was decoded on any dataset.

---

## 1. Why

Rung W10 is *both* a nonlinear feature map and a $G$-invariant one. Its accuracy therefore
attributes nothing to symmetry on its own: a map that is equally nonlinear and *not* invariant might
recover the same share of the gap, in which case W10's number measures feature engineering. The
review's wording:

> For W10, construct a non-invariant feature map with the same trigonometric orders, the same
> tensor-product degrees, the same dimensionality, the same pooling complexity, and the same reader
> parameter count. Only the group-invariance structure should differ.

This matters most on CIFAR-10, where W10 is the strongest weight-space result in the paper
($f = 0.534$) and the one an earlier draft quoted as though it were a reframing.

## 2. The control (`src/sirengap/canon/deep_control.py`, rung `W10c`)

Coordinate for coordinate, the same monomials in $(w,u)$ and the same trigonometric orders in $b$,
pooled by the same eigenvalue spectra and the same $\|w\|^2$ sort key, at the same dimension
($D = 320$ grayscale, $384$ CIFAR-10), decoded by the same frozen apparatus. Only the *parity class*
of each trigonometric factor is changed, so the emitted coordinates are no longer
$D_\infty$-invariant:

| W10 coordinate | W10c coordinate | residual sign |
|---|---|---|
| $(\sin b_i \sin b_l)G_{il}$ | $(\cos b_i \cos b_l)G_{il}$ | $(-1)^{d_i+d_l}$ |
| $(\cos b_i w_i\cdot\cos b_l w_l)G_{il}$ | $(\sin b_i w_i\cdot\sin b_l w_l)G_{il}$ | $(-1)^{d_i+d_l}$ |
| $(\sin 2b_i w_i\cdot\sin 2b_l w_l)$ | $(\cos 2b_i w_i\cdot\cos 2b_l w_l)$ | $(-1)^{d_i+d_l}$ |
| $\|w_i\|^2$ | $\sin(2b_i)\|w_i\|^2$ | $(-1)^{d_i}$ |
| $\cos 2b_i$ | $\sin b_i$ | $\varepsilon_i$ |
| $G_{ii}$ | $\cos(b_i)G_{ii}$ | $(-1)^{j_i}$ |
| $\|w^2_k\|^2$ | $\sin(2b^2_k)\|w^2_k\|^2$ | $(-1)^{d_k}$ |
| $\cos 2b^2_k$ | $\sin b^2_k$ | $\varepsilon_k$ |
| $\|u_k\|^2$ | $\cos(b^2_k)\|u_k\|^2$ | $(-1)^{j_k}$ |
| $(\sin b^2_k)u_k$ | $(\cos b^2_k)u_k$ | $(-1)^{d_k}$ |

The three matrices remain symmetric and still transform as $M \mapsto PMP^\top$, so the control is
**still exactly permutation-invariant** and is broken only in the $D_\infty$ component. That is
deliberate: it isolates the phase/reflection part — the part this paper claims prior classifications
do not cover — rather than confounding it with permutation handling. T15 asserts both properties:
relative move $> 10^{-2}$ under the full group, $< 10^{-5}$ under permutations alone.

## 4. What the outcomes license (pre-committed)

- **Falsifier.** If $f(\mathrm{W10c}) \ge f(\mathrm{W10}) - 0.05$ on CIFAR-10, W10's gain there is
  **not** separable from nonlinear feature engineering. The paper must then withdraw every reading
  of the CIFAR-10 W10 number as evidence about symmetry, report the control in the abstract, and
  quote $f(\mathrm{W5}) = 0.325$ as the only symmetry-attributable CIFAR-10 result.
- **If $f(\mathrm{W10c})$ lands materially below $f(\mathrm{W10})$**, the difference is reported as
  the invariance-attributable part of the encoding's gain, with the explicit caveat that it is
  attributable to the $D_\infty$ component specifically, since permutation invariance is held fixed
  across the two maps.
- **If $f(\mathrm{W10c}) > f(\mathrm{W4})$**, then nonlinear pooling contributes on its own and the
  encoding's advantage over template-free sorting is not purely a symmetry effect either; this must
  be stated wherever W10 is compared with W4.
