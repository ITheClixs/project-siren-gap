# S17 Pre-registration — replicating the shared initialization — FROZEN

**Study:** S17. Tests whether the anchor and the reframing result depend on the single draw of the
shared initialization $\theta_0$ used by every `P-shared-det` corpus.
**Frozen:** 2026-09-13, before any S17 corpus is fitted. Ledger rows `H-S17-*`, `P-S17-*`.

## 1. Why

Every `P-shared-det` INR is fitted from the same $\theta_0$ (init seed 0). W1, the $c_{\mathrm{align}}$
template and the orbit intervention therefore rest on one draw.

## 2. Design

MNIST, the reduced size and budget of S8's internal control (10k/2k/2k images, 300 steps,
constant-rate Adam, width 32, depth 2), so the new draws are compared like for like with
`P-shared-det-s8s300` (draw 0). Two new shared initializations are fitted with
`03_generate_inrbench.py --seed-offset 1` and `--seed-offset 2` (tags `s17o1`, `s17o2`). The
independent-initialization corpus `P-random-s8s300` is shared by all three draws.

Per draw $k \in \{0,1,2\}$, with the frozen decoder and 5 seeds:
- $\mathrm{W1}_k$: raw weights of the draw-$k$ shared corpus;
- $\mathrm{W5}_k$: `P-random-s8s300` aligned by $c_{\mathrm{align}}$ to the draw-$k$ template
  $\theta_0^{(k)}$;
- $f_k(\mathrm{W5}) = (\mathrm{W5}_k - \mathrm{W3})/(\mathrm{W1}_k - \mathrm{W3})$, with W3 the raw
  weights of `P-random-s8s300`;
- $\Delta_k$: the S6 intervention at $B = 0$ with permutations, on the draw-$k$ shared corpus.

Sanity check recorded per draw: median relative travel $\|\theta - \theta_0^{(k)}\|/\|\theta_0^{(k)}\|$,
which should be near S8's 0.19 if the template is the corpus's own initialization.

**Exposure (declared).** Draw 0 at this size was decoded in S8 (W1 − W3 gap 77.64,
$f(\mathrm{W5}) = 0.502$); its S17 values are recomputed on the same code path and not scored.
